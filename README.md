# Job Buddy

This is a local mobile-first browser prototype for handyman workers who need loud reminders, flexible timers, job-site alerts, and leaving checklists.

Open it from a web server so browser reminders and location permission can work. The app saves jobs in the browser on the device using it.

For full phone install and location support, host it on an HTTPS link. A same-Wi-Fi local link is good for checking the screens on a phone, but some phone browsers block install, location, and notifications unless the link is HTTPS.
